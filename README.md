# Odin-Hashmap

This project was made under The Odin Project Curriculum to better understand Hashmaps.
I implemented simple hashmap from scratch, using linked list. The implemented hashmap can auto resize if no. of mappings exceed ((load factor) * (capacity)).

---

## Methods Implemented
- hash
- set
- get
- has
- remove
- length
- clear
- keys
- values
- entries
- resize
